# ميد أوربت | MedOrbit

تطبيق عربي تجريبي لإدارة دليل الأطباء والمنتجات الخيالية وتقارير الزيارات المهنية، أُنشئ للهاكاثون الجامعي.

## ما الذي يعمل؟

- دليل أطباء قابل للبحث والتصفية، مع إضافة وتعديل وملف لكل طبيب.
- حقول الاسم والاختصاص والمنطقة والعنوان والإحداثيات التقريبية وأوقات استقبال المندوبين والاهتمامات العلمية.
- ثلاثة أطباء وثلاثة منتجات خيالية للعرض، تُضاف مرة واحدة دون استبدال التعديلات.
- نموذج تقرير زيارة مرتبط بطبيب ومنتج محفوظين، مع النتيجة والملاحظات المهنية والتاريخ.
- سجل تقارير ولوحة شركة تستعلم قاعدة البيانات فعليًا؛ لا توجد أرقام أداء مُختلقة.
- واجهة عربية من اليمين إلى اليسار، للهاتف والكمبيوتر.

## الخصوصية وحدود هذه المرحلة

هذه نسخة هاكاثون مفتوحة بلا تسجيل دخول أو فصل للصلاحيات، وليست نظامًا طبيًا أو نظام شركة جاهزًا للاستخدام الحقيقي. استخدم بيانات خيالية فقط.
لا تُدخل معلومات مرضى أو أرقام هواتف حقيقية أو صور وصفات أو سمات شخصية حساسة في أي حقل، بما فيه الملاحظات.
لا توجد وحدات رمز تحقق أو تخطيط مسارات أو موجز ذكاء اصطناعي أو واتساب أو صيدليات.
المنتجات خيالية بالكامل ولا تمثل أدوية ولا تُقدم توصيات علاجية.

## البنية

تطبيق واحد في مستودع واحد: واجهة React وTailwind، وخادم Node.js/Express واحد وقاعدة PostgreSQL دائمة، وليست خدمات مصغرة.

- `artifacts/medorbit` — الواجهة.
- `artifacts/api-server` — جميع واجهات الخادم.
- `lib/db` — مخطط قاعدة البيانات واتصالها.
- `lib/api-spec/openapi.yaml` — عقد الواجهات البرمجية.
- `lib/api-client-react` و`lib/api-zod` — العميل والتحقق المولّدان من العقد.

## التشغيل في Replit

شغّل التطبيق من المعاينة. خادما الواجهة والـAPI مُعرّفان مسبقًا.
تُدار قيمة `DATABASE_URL` سرّيًا بواسطة البيئة، ولا توجد أسرار ضمن هذا المستودع أو ملف التنزيل.

```sh
pnpm install --frozen-lockfile
pnpm --filter @workspace/db run push
pnpm run typecheck
```

ثم شغّل مساري التشغيل المعرّفين للمشروع:

- `pnpm --filter @workspace/api-server run dev`
- `pnpm --filter @workspace/medorbit run dev`

في Replit، مسارات التشغيل المُدارة توفّر إعدادات المنافذ والمسار تلقائيًا. لتشغيل نسخة خارج Replit، تحتاج PostgreSQL وقيمة `DATABASE_URL` آمنة، ومنفذًا للخادم، و`PORT` و`BASE_PATH=/` للواجهة، ووكيلًا واحدًا يوجّه `/api` للخادم وبقية المسارات للواجهة. لا تنقل قاعدة البيانات أو الأسرار عبر Git.

تُطبق تغييرات المخطط على قاعدة التطوير باستخدام الأمر `push` أعلاه. نشر Replit يدير ترحيل مخطط قاعدة الإنتاج؛ لا يوجد إنشاء جداول تلقائي عند بدء الخادم. بدء الخادم يضيف البيانات الخيالية المفقودة فقط.

## التحقق

اختبارات واجهة API فعلية ومُوثّقة في `docs/نتائج-الاختبارات.md`:

```sh
node scripts/verify-medorbit.mjs
# أعد تشغيل خادم API ثم:
node scripts/verify-medorbit.mjs --after-restart
```

الاختبارات تنشئ سجلات خيالية مؤقتة؛ معرّفاتها تُكتب في `generated-artifacts/verification-state.json` لتُنظَّف من قاعدة التطوير بعد التحقق. لا تستخدمها مع قاعدة الإنتاج. ليست اختبارات متصفح آلية.
