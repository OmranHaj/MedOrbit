# نتائج مخطّط الجولة التجريبي — Smart Route

التاريخ: ٣ نوفمبر ٢٠٢٦.

أُضيف المخطّط إلى التطبيق الحالي في `/smart-route`، مع ستة أطباء خياليين إضافيين في «منطقة الجولة التجريبية». لم تُستبدل ملفات الأطباء أو المنتجات أو التقارير السابقة، ولم يتغيّر مسار OTP.

## نتائج أوقات الانطلاق

**الانتظار الطويل مقصود ومرئي:** النوافذ متباعدة لإظهار الفرق بين الوصول وبدء الزيارة، ولا يوجد شرط لحد أقصى لمدة الجولة أو الانتظار في هذه النسخة.

| إضافة ستة أطباء بنوافذ مختلفة مع مطابقة جميع السجلات السابقة | نجح |
| بدء 09:00، والحصول على ست زيارات | نجح |
| بدء 11:30، والحصول على ثلاث زيارات وثلاثة أسباب استبعاد | نجح |

| تغير الزيارات عند تغيير وقت البدء وإدراج الانتظار | نجح |

| رفع مدة الزيارة إلى 60 دقيقة يستبعد النوافذ الأقصر | نجح |

| نافذة لم تُغلق بعد لكن الوصول المباشر لا يتيح إكمال الزيارة | نجح؛ سبب صريح للوصول غير الممكن ضمن النافذة |
| الحساب لا ينشئ تقارير أو زيارات معلقة أو جلسات OTP | نجح |
| تنظيف بيانات الاختبار وحدها وإعادة مقارنة السجلات السابقة | نجح |

تتحقق الاختبارات أيضًا من مسافة كل مرحلة بمعادلة مستقلة، وتحويلها إلى وقت بالسرعة المدخلة، وترابط الوصول والمغادرة والانتظار، وعدم تجاوز نهاية النافذة، وصحة المجاميع، وظهور كل طبيب مرة واحدة إما في الجولة أو في قائمة الاستبعاد.

أُعيد تشغيل `scripts/verify-visit-otp.mjs`: **18 من 18 نجحت**، بما فيها إنشاء وتعديل وبحث الأطباء، حفظ تقرير مؤكد واسترجاعه، تحديث لوحة الشركة، رفض الرمز الخاطئ والمعاد والمنتهي، وحد المحاولات والطلبات المتزامنة. نُظّفت بيانات الاختبار دون تغيير السجلات الأصلية.

نجح فحص TypeScript الكامل وبناء الواجهة. جرت مراجعة صورة معاينة فعلية لصفحة المخطّط بعرض هاتف 390 بكسل دون خطأ JavaScript أو تجاوز عرض ظاهر. **لم تُجرَ جولة نقر آلية جديدة في المتصفح** لهذا الامتداد القرائي؛ اختبارات الأوقات والحسابات والتراجع كانت عبر API الفعلية، وليست صورًا أو بيانات نموذجية ثابتة.

## حدود الحساب

- مسافة هافرسين جغرافية على سطح الكرة الأرضية وليست طول طريق أو نتيجة خرائط فعلية. زمن الانتقال = المسافة ÷ السرعة، مع التقريب لأعلى دقيقة.
- السرعة ثابتة ومعلنة وقابلة للتغيير؛ لا حركة مرور حية أو GPS أو تقدير طرق ومواقف.
- الخوارزمية جشعة بنظرة قصيرة للأمام: تفضل مرشحًا يترك عددًا أكبر من الأطباء الممكن الوصول إليهم منفردين، ثم وقت انتقال وانتظار أقل، ثم مسافة أقل. لا يعني ذلك أن هؤلاء الأطباء جميعًا يمكن جمعهم في مسار واحد، ولا يضمن أكبر عدد زيارات أو مسارًا أمثل عالميًا.
- يجب إكمال الزيارة كلها داخل نافذة الاستقبال. الدخول قبل الإغلاق بدقيقة لا يكفي لزيارة مدتها 15 دقيقة.
- يوم محلي افتراضي واحد؛ لا نوافذ تعبر منتصف الليل أو استراحات أو عودة لنقطة الانطلاق، وبحد 100 طبيب لكل منطقة. تجاوز الحد ينتج خطأ واضحًا دون استبعاد صامت.
- النتيجة اقتراح مؤقت، وليست حجزًا أو إثبات زيارة أو تأكيد OTP. إعادة التحميل لا تحذف سجلات التطبيق، لكنها تتطلب حساب الاقتراح من جديد.
- لم تُضف خريطة لأن القائمة المرقمة توصل النتيجة دون الاعتماد على خدمة خارجية غير موثوقة في العرض.

## تجربة العرض

افتح «الجولة»، واختر المنطقة التجريبية والنقطة الجنوبية. اضغط «احسب الجولة» عند 09:00، ثم غيّر الوقت إلى 11:30 وأعد الحساب، ثم 16:00. تعرض الصفحة وصول كل زيارة وبدءها ومغادرتها وترتيبها والمسافة والانتظار، ثم المستبعدين وأسبابهم. إذا تغيّرت المدخلات، تُوسم النتيجة السابقة بأنها تحتاج إعادة حساب.
